## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico**: Estrutura acessível com tags SEO e OpenGraph para compartilhamento em redes sociais.
- **CSS3 Puro (Vanilla CSS)**: Design system com variáveis personalizadas, tema dark obsidian, acentos em vermelho neon (`#FF1E27`), glassmorphism e animações suaves.
- **JavaScript Moderno (ES6+)**:
  - Calculadora interativa de IMC com ponteiro dinâmico e integração com WhatsApp.
  - Grade de horários com filtros por dias da semana.
  - Carrossel de depoimentos com auto-play e controles táteis.
  - Galeria com modal lightbox em tela cheia.
  - Efeito ambient glow que segue o cursor do usuário.
- **Google Maps API**: Embed da localização e botão para traçar rotas direto no aplicativo.

## 📦 Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/academia-isad-fit.git
   ```
2. Abra o arquivo `index.html` diretamente no seu navegador ou inicie um servidor local:
   ```bash
   # Com Python
   python -m http.server 8080
   
   # Ou com Node.js
   npx serve
   ```
3. Acesse `http://localhost:8080` no navegador.
